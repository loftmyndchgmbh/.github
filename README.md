**Über uns**

Loftmynd.ch GmbH ist ein Softwareentwicklungsunternehmen mit Sitz in der Schweiz. In diesem GitHub-Bereich organisieren wir unsere Codebasis und entwickeln innovative Webapplikationen für unsere Kunden. Unser Fokus liegt auf der Entwicklung massgeschneiderter Lösungen, die den spezifischen Anforderungen unserer Kunden entsprechen und ihnen helfen, ihre Geschäftsziele zu erreichen. Wir setzen auf moderne Technologien und agile Methoden, um qualitativ hochwertige und effiziente Webapplikationen zu liefern.

**Beitragsrichtlinien (Intern)**

Dieses Repository ist für die interne Nutzung durch das Entwicklungsteam von Loftmynd.ch GmbH bestimmt. Wenn Sie als Entwickler zu Projekten beitragen, beachten Sie bitte folgende Richtlinien:

1.  Erstellen Sie einen neuen Branch für Ihre Feature- oder Bugfix-Änderung.
2.  Stellen Sie sicher, dass Ihr Code den internen Coding-Standards entspricht.
3.  Reichen Sie einen Pull Request ein, der Ihre Änderungen detailliert beschreibt, bevor Sie diese mergen.
4.  Für Fragen oder Unklarheiten wenden Sie sich bitte an das IT-Team.
